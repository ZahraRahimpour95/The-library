# The-libraryمدیریت کتابخانه

سیستم مدیریت کتابخانه
هدف پروژه
در این پروژه شما قرار است یک سیستم مدیریت کتابخانه ساده طراحی و پیاده‌سازی کنید. هدف این است که با استفاده از جنگو و قالب‌های آن، تجربه‌ای عملی از ساخت یک وب‌اپلیکیشن کامل با قابلیت‌های مدیریت داده‌ها به دست آورید.

قابلیت‌های مورد انتظار
1. افزودن کتاب جدید: کاربران بتوانند کتاب‌های جدید را به فهرست اضافه کنند.

2. مشاهده لیست کتاب‌ها: کاربران بتوانند تمام کتاب‌های موجود در کتابخانه را مشاهده کنند.

3. جستجو: کاربران بتوانند اطلاعات مربوط به یک کتاب خاص یا لیست کتاب‌های یک نویسنده را با وارد کردن نام کتاب یا نام نویسنده مشاهده کنند.

4. ویرایش کتاب: کاربران بتوانند اطلاعات کتاب‌های موجود را ویرایش کنند.

5. حذف کتاب: کاربران بتوانند کتاب‌های موجود را حذف کنند.

6. فیلتر کردن کتاب‌ها: امکان فیلتر کردن کتاب‌ها براساس معیارهایی مانند قیمت یا تاریخ انتشار فراهم باشد.

7. حذف با فیلتر: کاربران بتوانند تمام کتاب‌هایی را که پس از فیلتر نمایش داده شده‌اند حذف کنند.

امتیازهای اضافی (اختیاری)
عزیزانی که علاقه‌مند هستند پروژه خود را فراتر از الزامات اصلی توسعه دهند، می‌توانند موارد زیر را پیاده‌سازی کنند. اجرای این قابلیت‌ها الزامی نیست اما در صورت انجام، امتیاز بیشتری برای پروژه در نظر گرفته خواهد شد:

نکات مهم
قبل از شروع پیاده‌سازی، لازم است نمودار ER مورد نیاز را طراحی کنید.

برای پیاده‌سازی باید از مفاهیم جنگو و جنگو تمپلیت استفاده کنید.

برای نمایش داده‌ها قالبی مناسب طراحی کنید تا اطلاعات به شکلی خوانا و کاربرپسند نمایش داده شوند.

استفاده از گیت در این پروژه ضروری است. در پایان کافی است لینک ریپازیتوری گیت‌هاب خود را در یک فایل متنی قرار داده و ارسال کنید.
